# AMAZON Q — VISUAL DESIGN IMPLEMENTATION DIRECTIVE

## Objective

Implement the Natalie Flemons website using the approved visual mockup as the primary design reference.

The goal is to reproduce its overall visual appearance, design language, section hierarchy, content composition, and professional editorial presentation as closely as practical within the existing Next.js application.

This directive supplements the previously established website architecture requirements.

## Visual Reference

Use the provided Natalie Flemons multi-page visual mockup as the target design.

The mockup includes the homepage, About page, 2027 Events page, Books page, Media page, and footer navigation.

If the reference image is not accessible to your development environment, request its project path before implementation. Do not claim to have examined an inaccessible image.

## Design Requirements

**Homepage:** Reproduce the two-column hero, portrait treatment, cream background, copper CTAs, biography section, dark ministry section, featured video, featured publications, forest-green events promotion, partnership section, and compact footer.

**About:** Reproduce the large editorial introduction, prominent portrait, biography presentation, and My Story navigation. Include an approved autobiography narrative.

**Events:** Reproduce the 2027 annual schedule presentation with responsive month cards, event categories, event listings, and a separate invitation-to-speak section.

**Books:** Reproduce the refined publication grid with consistent book-cover presentations, individual details, descriptions, and approved purchasing actions.

**Media:** Reproduce the curated Facebook video gallery with featured content, category filters, responsive video cards, and approved playback integrations.

**Store:** Preserve a separate Store route accessible from the footer. Do not place Store in the primary header navigation.

## Visual Fidelity

Match the reference's:

- Layout proportions and alignment
- Editorial serif typography
- Warm cream and sand backgrounds
- Copper accents
- Dark espresso and forest-green sections
- Image placement and aspect ratios
- Section transitions and whitespace
- Button and card styling
- Overall premium, ministry-first presentation

Use actual approved photographs, book covers, and website content. Do not treat AI-generated mockup imagery, fictional event listings, or placeholder book artwork as verified source material.

## Responsive Implementation

The mockup represents a desktop design direction.

Create corresponding mobile and tablet layouts that maintain visual consistency while prioritizing usability, readability, navigation, and accessibility.

## Execution

First complete the previously requested architecture audit and obtain approval.

Then implement the approved design using reusable Next.js components and the existing project structure.

Compare actual browser screenshots against the reference image at each major implementation milestone.

Document deviations, missing assets, implementation limitations, and decisions requiring approval.

Do not report visual fidelity or functional success without performing the corresponding checks.

## Acceptance Criteria

The finished website should visibly resemble the approved mockup, retain authentic Natalie Flemons branding, and provide working navigation and integrations across all approved pages.

Visual fidelity, responsive functionality, accessibility, and maintainable code are equally important.
